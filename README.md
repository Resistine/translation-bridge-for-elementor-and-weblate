# Translation Bridge for Elementor and Weblate

Translation Bridge for Elementor and Weblate WordPress Plugin allows to translate Elementor pages with Weblate and optionally Polylang.

See [`readme.txt`](readme.txt) for the full WordPress plugin documentation.
